# 氣候與災害系統 (Climate & Disaster System)

WebCity 模擬四季變化和隨機天災事件。

---

## 氣候類型

| 氣候 | 說明 |
|------|------|
| TEMPERATE (溫帶) | 四季溫和 |
| TROPICAL (熱帶) | 夏季高水需求 |
| ARID (乾旱) | 夏季高水+高電需求 |
| CONTINENTAL (大陸性) | 冬季嚴寒 |

---

## 季節效果

### 春季
- 幸福度 +5

### 夏季
- 熱帶: 用水需求 ×1.2
- 乾旱: 用水需求 ×1.3，用電需求 ×1.1

### 秋季
- 無特殊效果

### 冬季
- 用電需求 ×1.3
- 幸福度 -5
- 大陸性氣候: 用電需求 ×1.5，幸福度 -8

## 災害系統

### 災害類型

| 類型 | 半徑 | 持續 | 傷害模式 |
|------|------|------|---------|
| EARTHQUAKE (地震) | 10 | 5 ticks | 距離衰減 |
| TORNADO (龍捲風) | 15 | 10 ticks | 帶狀路徑 (寬 3 格) |
| TSUNAMI (海嘯) | 20 | 8 ticks | 距離衰減 ×0.8 |
| FOREST_FIRE (森林大火) | 8 | 15 ticks | 距離衰減 ×0.7 |
| METEOR (隕石) | 6 | 3 ticks | 直擊 +衰減 |

### 傷害計算

所有災害使用基於震央的歐幾里得距離計算傷害：

**地震**: `intensity × (1 - distance / radius)`

**龍捲風**: 帶狀路徑（寬度 1.5 格），垂直距離和沿路距離的雙重衰減

**海嘯**: `intensity × (1 - distance / radius) × 0.8`

**森林大火**: `intensity × (1 - distance / radius) × 0.7`

**隕石**:
- 直擊半徑 1 格內: 完整 intensity
- 其他: `intensity × 0.6 × (1 - distance / radius)`

### 隨機災害

- **觸發機率**: 0.1%/tick（約每 1000 ticks / ~4 遊戲月一次）
- **最低人口**: 50 人才會觸發
- **強度**: 0.3 ~ 0.8 隨機
- **可觸發類型**: 地震、龍捲風、森林大火

### 災害傷害

- 傷害 > 0.5 的格子上的建築被摧毀
- **基礎設施免疫**: 電廠、水廠等基礎設施不會被災害摧毀
- **道路免疫**: 道路不會被災害摧毀

## 建築損傷系統 (Damage System)

### 損傷狀態

| 屬性 | 說明 |
|------|------|
| `damageLevel` | 損傷程度 (0~1) |
| `repairCost` | 修復費用 = damageLevel × $2000 |
| `destroyed` | 損傷 ≥ 0.9 時視為摧毀 |

### 道路損傷

道路損傷閾值: 0.3。傷害超過此值的道路格會受損。

### 修復

```
repairBuilding(state, funds):
  若 funds < repairCost → 修復失敗
  否則 → 修復成功，扣除 repairCost
```

## 預警系統 (Warning System)

預警塔可以減少災害造成的傷亡。

### 預警塔 (Warning Tower)

- 每座塔有位置 (x, y) 和覆蓋半徑
- 歐幾里得距離在半徑內的區域視為「已預警」

### 預警效果

- 預警覆蓋區域內，傷亡減少 50% (`CASUALTY_REDUCTION = 0.5`)

### 疏散

`calculateEvacuationTarget()` 為受災市民計算最近的避難所位置。
