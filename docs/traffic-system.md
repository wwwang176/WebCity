# 交通系統 (Traffic System)

WebCity 的交通系統模擬車輛在車道級別的移動，包含通勤、貨運和服務車輛。

---

## 車輛 (Vehicle)

### 車輛屬性

| 屬性 | 說明 |
|------|------|
| `id` | 唯一識別碼 |
| `length` | 車體長度（世界座標） |
| `width` | 車體寬度（世界座標） |
| `lane` | 所在車道（0-based） |
| `edgePath` | 路徑邊列表 |
| `edgeIndex` | 當前邊索引 |
| `edgeProgress` | 當前邊上的行進距離 |
| `speedMultiplier` | 隨機速度因子 (0.8~1.0) |
| `stallTime` | 停滯累計時間（秒），超過 30 秒則強制消失 |
| `arrived` | 是否已到達目的地 |

### 車輛類型

根據車體長度分類：

| 長度 | 類型 | 權重 |
|------|------|------|
| ≥ 0.58 | bus (公車) | - |
| ≥ 0.35 | truck (卡車) | 10% |
| ≥ 0.24 | van (貨車) | 15% |
| < 0.24 | car (轎車) | 75% |

### 服務車輛

| 類型 | 長度 | 寬度 |
|------|------|------|
| police (警車) | 0.22 | 0.09 |
| fire (消防車) | 0.55 | 0.125 |
| health (救護車) | 0.30 | 0.10 |
| garbage (垃圾車) | 0.45 | 0.125 |

## 車道圖 (LaneGraph)

### 概念

LaneGraph 將格子級的道路網路轉換為車道級的連線圖，支援精確的車輛移動模擬。

### 組成

- **ConnectionPoint（連接點）**: 每個道路格子的每條車道在每個方向都有 entry（進入）和 exit（出發）點
- **LaneEdge（車道邊）**: 連接兩個 ConnectionPoint 的路段

### 邊類型

| 類型 | 說明 |
|------|------|
| `straight` | 直行路段 |
| `turn` | 轉彎路段（使用 Bezier 曲線） |
| `lane_change` | 換道路段 |
| `merge` | 合流路段 |

### 車道寬度

每條車道的橫向偏移: `LANE_WIDTH = 0.18` 格

### 路口判定

roadFlags 中有 3 個以上方向旗標的格子為路口（intersection）。路口內的格子是「透明的」，不產生自己的連接點。

## 車輛移動

### 基礎速度

```
邊速度 = EDGE_SPEED × (道路速限 / REFERENCE_LIMIT) × speedMultiplier × 壅塞速度倍率
```

- `EDGE_SPEED` = 14 世界單位/秒
- `REFERENCE_LIMIT` = 50（速限 50 = 1.0 倍速）

### 前方碰撞偵測

車輛在前方 5 個世界單位內檢查：
1. 同邊上的前方車輛
2. 紅燈距離
3. 跨邊的 AABB 碰撞（合流路口）

### 停滯消失

車輛停滯超過 30 秒 → 強制消失。初始有 0~5 秒的隨機抖動。

### 公車特殊行為

公車到站時會停靠 2 秒（`BUS_DWELL_SECONDS`），期間不移動。

---

## 壅塞 (Congestion)

### 壅塞率

```
壅塞率 = 車輛數 / 容量
```

### 速度倍率

| 壅塞率 | 速度倍率 |
|--------|---------|
| ≤ 0.5 | 1.0（正常） |
| ≤ 0.8 | 0.8（中度壅塞） |
| ≤ 1.0 | 0.5（嚴重壅塞） |
| > 1.0 | max(0.05, 1 - 壅塞率) |

## 紅綠燈 (Traffic Lights)

### 放置規則

只有在 **兩條主要道路** (FOUR_LANE 或 SIX_LANE) **同時在南北和東西兩個軸向交叉**的路口才會設置紅綠燈。

### 相位

| 相位 | 南北 | 東西 |
|------|------|------|
| 0 | 綠燈 | 紅燈 |
| 1 | 紅燈 | 綠燈 |

### 相位時間

- 3 方向路口: 2 秒
- 4 方向路口: 4 秒

相位開始時有基於位置的隨機偏移，避免所有紅綠燈同步。

## 貨運系統 (FreightSystem)

### 運作流程

每 tick：
1. 工業建築產生貨物（每棟 2 單位/tick）
2. 商業建築消耗貨物（每棟 1 單位/tick）
3. 產生的貨物進入倉儲
4. 消耗量從倉儲扣除
5. 不足的部分為缺貨量

### 外部貨物來源

- **鐵路貨運**: 每列貨運火車 +10 貨物/tick
- **機場貨運**: 消耗機場的貨物配額
- **鐵路外部連接**: 連接地圖邊緣的鐵路可帶入外部貨物

### 缺貨影響

缺貨比例 = 缺貨量 / 消耗量（0~1）。缺貨會影響商業區的成長。

```
上限 = min(2000, 20 + 人口 × 0.3)
```

## 通勤系統

### 通勤快取 (CommuteCache)

儲存市民的通勤路徑（LaneEdge 序列），避免每次重新計算。

### 通勤產生

在早高峰和晚高峰時段，模擬從住所到工作場所的車輛移動：
- 每 tick 最少產生 5 輛通勤車
- 高峰持續 4 ticks
- 已通勤的市民不會重複產生

## 行人系統 (Pedestrian System)

### 行人代理 (PedestrianAgent)

每個行人是獨立的代理，在人行道圖上移動。

| 屬性 | 說明 |
|------|------|
| `citizenId` | 對應的市民 ID |
| `tripType` | 行程類型 |
| `edgePath` | 人行道邊路徑 |
| `state` | 當前狀態 |
| `speedMultiplier` | 個人速度倍率 (0.5~1.0) |
| `lateralOffset` | 隨機橫向偏移（視覺效果） |
| `age` | 已存活秒數（超過 120 秒消失） |

### 行程類型

| 類型 | 說明 |
|------|------|
| `FULL_WALK` | 完整步行通勤 |
| `FIRST_MILE` | 第一哩（住所到大眾運輸站） |
| `LAST_MILE` | 最後一哩（大眾運輸站到目的地） |
| `DECORATIVE` | 裝飾性行人（隨機出現在人行道上） |

### 行人狀態

| 狀態 | 說明 |
|------|------|
| `WALKING` | 行走中 |
| `WAITING_SIGNAL` | 等紅綠燈 |
| `WAITING_CROSSING` | 等待過馬路 |
| `ARRIVED` | 已到達目的地 |

### 行人數量限制

```
上限 = clamp(人口 × 5%, 50, 2000)
```

裝飾性行人最多佔 15%。

### 行人速度

基礎速度: 1.5 世界單位/秒

## 人行道圖 (SidewalkGraph)

### 節點類型

| 類型 | 說明 |
|------|------|
| `sidewalk` | 人行道節點 |
| `crosswalk_wait` | 斑馬線等候點 |
| `building_entrance` | 建築入口 |
| `transit_stop` | 大眾運輸站點 |

### 邊類型

| 類型 | 說明 |
|------|------|
| `sidewalk` | 人行道段 |
| `crosswalk` | 斑馬線（過馬路） |
| `level_crossing` | 平交道穿越 |
| `building_access` | 建築出入口通道 |
| `transit_access` | 大眾運輸站通道 |

### 人行道生成規則

- 人行道節點沿道路邊緣生成（無相鄰道路的那一側）
- 人行道寬度: 0.14 世界單位
- 斑馬線連接路口兩側的等候點
