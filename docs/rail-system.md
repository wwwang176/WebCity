# 鐵路系統 (Rail System)

鐵路提供高容量的長距離運輸，包含客運和貨運兩種服務。

---

## 軌道類型

```
NONE     = 0  無軌道
STANDARD = 1  標準軌道
```

## 軌道方向

使用與道路相同的 4 方向位元旗標：

```
NORTH = 0b0001
SOUTH = 0b0010
WEST  = 0b0100
EAST  = 0b1000
```

---

## 軌道建設

### 費用

每格 $150 (`COST_PER_CELL`)。已有軌道的格子免費（只合併方向旗標）。

### 建設規則

1. 使用 L 形路徑（先水平後垂直）
2. 不可建在水域或山地
3. 不可建在已有基礎設施的格子
4. **不可與同格道路平行**：
   - 垂直軌道 + 垂直道路 = 衝突
   - 水平軌道 + 水平道路 = 衝突
   - 垂直軌道 + 水平道路 = 允許（形成平交道）

### 與道路共存

軌道和道路可以在同一格交叉（平交道），但不能平行。

---

## 平交道系統 (Level Crossing)

當鐵路和道路在同一格交叉時形成平交道。

### 平交道偵測

系統自動掃描地圖上同時有 `railType != NONE` 和 `roadType != NONE` 的格子，將其標記為平交道。

### 平交道狀態

| 狀態 | 說明 |
|------|------|
| `CLEAR` | 暢通，車輛可通過 |
| `ACTIVE` | 柵欄放下，車輛不可通過 |

### 啟動機制

- **啟動半徑**: 曼哈頓距離 2.5 格
- 當火車進入啟動半徑內 → 平交道變為 ACTIVE
- **冷卻時間**: 火車離開後保持 ACTIVE 1.5 秒
- 冷卻結束 → 恢復 CLEAR

### 軌道方向判定

平交道記錄鐵軌的通過方向：
- 有垂直旗標 (N/S) → `NS` 方向
- 否則 → `EW` 方向

---

## 軌道網路 (RailNetwork)

繼承自 `GraphNetwork`，提供與道路網路相同的圖操作（BFS 連通性判定等）。
