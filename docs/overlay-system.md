# 覆蓋層系統 (Overlay System)

覆蓋層提供各種遊戲資料的視覺化，幫助玩家理解城市狀態。

---

## 可用覆蓋層

| 覆蓋層 | 數據來源 | 顯示方式 |
|--------|---------|---------|
| power | 電力覆蓋 | 有電=綠(100)、電力不足=黃(50)、無電=紅(15) |
| water | 供水覆蓋 | 有水=亮藍(100)、供水不足=黃(50)、無水=紅(15)、地下水=深藍 |
| zone | 區域規劃 | 按 zoneType 值著色 |
| traffic | 交通密度 | `log2(1 + 車流) × 10`，上限 100 |
| pollution | 污染程度 | 0~100 映射 |
| landValue | 地價 | 僅有建築的格子顯示，0~100 映射 |
| crime | 犯罪率 | 基礎值 40 + 警察減少值 |
| district | 行政區 | 按區域 ID 雜湊著色 |
| police | 警察覆蓋 | 有覆蓋=80 |
| fire | 消防覆蓋 | 有覆蓋=80 |
| health | 醫療覆蓋 | 有覆蓋=80 |
| education | 教育覆蓋 | 有覆蓋=80 |
| park | 公園覆蓋 | 有覆蓋=80 |
| garbage | 垃圾覆蓋 | 有覆蓋=80 |
| commute | 住戶的平均通勤時間 | 綠→紅，60（換工作的門檻）為滿格 |

---

## 顏色畫在哪裡

覆蓋層同時畫兩層：**地面**與**建築**。

地面是一張蓋滿全圖的半透明色塊，拉遠看城市時給的是區域層級的樣貌。建築則是逐棟
上色 —— 密集的住宅區裡，地面會被建築本身擋住，玩家看到的是屋頂。所以「這一棟好
不好」一定要畫在建築上。

道路距離類的服務（警／消／醫／校／垃圾）與通勤時間都是逐棟漸層：綠 → 黃 → 紅。
電力與供水則是三態（有／不足／無），不是連續值。

地面那一層的繪製順序排在建築與地面貼片**之前**，所以貼片畫在色塊上面 —— 玩家同時
看得到「這一格的數值」與「這裡有什麼」。這件事必須明講：建築材質是半透明的，三者
在同一個繪製批次裡，而 three.js 對透明物件是按物件中心點到鏡頭的距離排序 —— 覆蓋層
是單一一張蓋滿全圖的網格，中心點只有一個，不指定順序的話鏡頭一轉前後關係就翻面
（BUG-275）。

## 通勤時間覆蓋層

住宅建築依**住戶的平均通勤時間**上色，並標出所有大眾運輸站牌（青色）。

刻度是絕對值而不是相對最大值：滿格就是[換工作的門檻](citizen-system.md#通勤時間)。
相對刻度會讓一座通勤全都很好的城市裡最慢的那一格照樣變紅 —— 紅色必須永遠代表
「這裡的人真的過得不好」。

沒有通勤人口的格子完全不上色；有住戶但通勤極短的仍然上一點色，這樣空地與「通勤
很短」在畫面上分得開。

站牌標記讓「這片紅色離最近的站有多遠」看得出來 —— 那正是這張圖要回答的問題。

資料是模擬迴圈每 60 tick 算一次的統計，不是格子上的欄位，所以**不進存檔**（可以
從現有狀態重算）。載入結束時會先算一次，玩家進到遊戲時顏色已經在了。統計換版時
圖層會重建，否則它會是一張死的快照（BUG-277）。

同一份統計也餵給 Overview → Traffic 分頁的通勤面板。

## 顯示比例常數

| 常數 | 值 | 說明 |
|------|-----|------|
| DISPLAY_MAX | 100 | 覆蓋層最大顯示值 |
| RAW_MAX | 255 | 原始資料最大值 |
| GROUNDWATER_FACTOR | 0.4 | 地下水倍率 |
| ZONE_TYPE_FACTOR | 15 | 區域類型倍率 |
| TRAFFIC_LOG_FACTOR | 10 | 交通密度的對數刻度倍率 |
| CRIME_BASE | 40 | 犯罪率基礎值 |
| COVERAGE_VALUE | 80 | 布林覆蓋顯示值 |

## 電力覆蓋層特殊邏輯

| 狀態 | 顏色 | 值 |
|------|------|-----|
| 已供電 | 綠色 | 100 |
| 在範圍內但電力不足 (supplyRatio < 1) | 黃色 | 50 |
| 有建築但無覆蓋 | 紅色 | 15 |
| 空地 | 透明 | 0 |

## 供水覆蓋層特殊邏輯

| 狀態 | 顏色 | 值 |
|------|------|-----|
| 已供水 | 亮藍 | 100 |
| 在範圍內但供水不足 | 黃色 | 50 |
| 有建築但無覆蓋 | 紅色 | 15 |
| 有地下水 | 深藍 | max(8, 地下水 × 8) |
| 空地無水 | 透明 | 0 |
