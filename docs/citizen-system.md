# 市民系統 (Citizen System)

城市的人口不是一個數字，而是一群各自獨立的市民。每一位都有自己的年齡、教育程度、
幸福度與健康值，自己找房子、自己找工作，不滿意就自己搬走。

這份文件說明市民會依什麼條件做出這些決定 —— 蓋什麼、稅收多少、污染多重，最後都是
透過這些條件影響人口。

---

## 生命階段 (Life Stage)

使用「生命週」(life-weeks) 作為年齡單位。完整一生約 260 週（遊戲時間約 5 年）。

### 年齡增長

```
每 tick 增加年齡 = AGE_PER_TICK = 0.006 life-weeks
```

在 3 倍速下，一個市民從出生到自然死亡約需 1 小時現實時間。

### 階段劃分

| 階段 | 年齡範圍 (life-weeks) | 說明 |
|------|----------------------|------|
| BABY | 0 ~ 8 | 嬰兒，不可工作或就學 |
| CHILD | 9 ~ 32 | 兒童，可就讀小學 |
| TEEN | 33 ~ 52 | 青少年，可就讀高中 |
| ADULT | 53 ~ 200 | 成人，可工作、可就讀大學 |
| SENIOR | 201+ | 老年，退休 |

### 工作年齡

只有 ADULT 階段（53~200 life-weeks）的市民可以工作。TEEN 和 SENIOR 不被視為工作人口。

## 死亡系統

每天進行一次死亡判定（浴缸曲線 + 醫院負載 + 污染）。

### 死亡率公式

```
finalRate = baseRate × elderlyMult × hospitalMult × pollutionMult
```

### 基礎死亡率 (baseRate)

| 階段 | 每日死亡率 | 無醫療存活率 |
|------|-----------|-------------|
| BABY | 0.0016 | ~91% |
| CHILD | 0.00015 | ~98% |
| TEEN | 0.00015 | ~98% |
| ADULT | 0.0005 | ~60% |
| SENIOR | 0.006 | ~8% |

### 修正因子

- **高齡加成 (elderlyMult)**: age > 240 時，每多 1 life-week 死亡率倍率 +0.25
- **醫院負載 (hospitalMult)**: 依醫院負載率連續變化（詳見[醫療服務](services-system.md#醫院負載系統)）
  - 有覆蓋且負載 ≤ 100%: × 0.3（降低 70%）
  - 有覆蓋且負載 100%~200%: × 0.3~1.0（線性惡化）
  - 有覆蓋且負載 ≥ 200%: × 1.0（等同無覆蓋）
  - 無覆蓋: × 1.0
- **污染懲罰 (pollutionMult)**: 無醫院覆蓋時，住所污染增加死亡率
  - 有覆蓋: × 1.0（污染效果已透過醫院超載反映）
  - 無覆蓋: × (1 + 0.5 × pollution/255)，最高 × 1.5
- **硬性上限**: age > 280 → 立即死亡

### 範例（SENIOR，base=0.006）

| 情境 | 計算 | 日死亡率 |
|------|------|---------|
| 有醫院、無污染 | 0.006 × 0.3 × 1.0 | 0.0018 |
| 有醫院、高污染但未超載 | 0.006 × 0.3 × 1.0 | 0.0018 |
| 有醫院、超載 150% | 0.006 × 0.65 × 1.0 | 0.0039 |
| 無醫院、無污染 | 0.006 × 1.0 × 1.0 | 0.006 |
| 無醫院、高污染 | 0.006 × 1.0 × 1.5 | 0.009 |

### 醫院蓋了會怎樣、不蓋會怎樣

**蓋了醫院**，覆蓋範圍內的死亡率降到三成，而且污染對死亡率的影響直接歸零 ——
醫院同時擋掉了老化與污染兩件事。健康值也會加 0~30，越靠近加越多。

**不蓋醫院**，城市不會崩潰，但會停在一個低天花板：老年市民日死亡率 0.6%，人口
到一定規模後死亡數與出生數打平就上不去了。污染區的住宅還會再乘 1.5 倍。

**醫院會超載**，而超載的醫院等於沒蓋 —— 負載 200% 以上倍率回到 1.0。人口成長時
只蓋一間會在某個時點靜靜地失效，症狀是死亡率突然回升但覆蓋圖看起來仍然是綠的。

## 健康值 (Health)

每位市民的健康值 (0~100) 影響死亡率和生活品質。

### 基礎值: 50

### 加成因素

| 因素 | 效果 | 說明 |
|------|------|------|
| 醫院覆蓋 | +0~30 | `(1 - costRatio) × 30`，越近加成越高 |
| 公園覆蓋 | +5 | 住所在公園覆蓋範圍內 |
| 有住所 | +10 | 有家的市民比無家可歸者更健康 |

### 減損因素

| 因素 | 效果 | 說明 |
|------|------|------|
| 污染 | -0~15 | `(pollution / 100) × 15` |
| 老年衰退 | -0~10 | age > 200 時線性增加 |

### 計算公式

```
health = 50
  + 醫院覆蓋加成 (0~30，基於道路距離)
  + 公園覆蓋加成 (+5)
  - 污染懲罰 (0~15)
  + 有住所加成 (+10)
  - 老年衰退 (0~10，age 201~260 線性)
clamp(0, 100)
```

## 教育系統

### 教育等級

```
NONE        無教育
ELEMENTARY  小學
HIGH_SCHOOL 高中
UNIVERSITY  大學
```

### 升學路徑

```
NONE → ELEMENTARY（需要小學覆蓋）
ELEMENTARY → HIGH_SCHOOL（需要高中覆蓋）
HIGH_SCHOOL → UNIVERSITY（需要大學覆蓋）
```

### 畢業時間

| 學校 | 兒童/青少年耗時 | 成人耗時 | 老年耗時 |
|------|---------------|---------|---------|
| 小學 | 150 ticks | ~455 ticks | 750 ticks |
| 高中 | 120 ticks | ~364 ticks | 600 ticks |
| 大學 | 100 ticks | ~303 ticks | 500 ticks |

### 學習速度

| 年齡段 | 每 tick 進度 |
|--------|-------------|
| 兒童/青少年 (≤52 wk) | 100 |
| 成人 (53~200 wk) | 33（約 3 倍慢） |
| 老年 (201+ wk) | 20（5 倍慢） |

每 tick 有 80%~120% 的隨機抖動，使畢業時間自然分散。

### 教育 Tick 流程

**Phase 1 — 推進已在學的學生**:
1. 已在學的學生（`educationProgress > 0`）
2. 若失去住所或學校覆蓋 → 暫停（不重置進度）
3. 進度 += jitteredSpeed(學習速度)
4. 進度達到門檻 → 畢業，教育等級提升

**Phase 2 — 招收新生**:
1. 有住所、未在學、年齡 ≥ 9 的市民
2. 住所在學校覆蓋範圍內
3. 學校有剩餘容量
4. → 開始就學

### 學校蓋了會怎樣、不蓋會怎樣

教育程度是市民身上影響最廣的一項屬性 —— 它同時決定了這個人住哪、做什麼工作、
生幾個小孩、多久才會受不了搬走。

**蓋了小學**，兒童才會開始升學。這是整條升學路徑的入口：沒有小學，全城市民永遠停在
無教育，後面兩所學校蓋了也收不到學生（升高中要先有小學學歷）。

**蓋了高中**，市民才進得了辦公室不被扣分（無教育與小學學歷在辦公室工作會扣幸福度），
失業容忍度也從 90 拉到 105 —— 找不到工作時能多撐一段時間才移出。

**蓋了大學**，效果在城市層級而不只是個人：

- 城市有大學會提高**移入者**的教育分布（大學 +15、高中 +5）。這是唯一能主動改變
  移入人口素質的手段。
- 大學畢業的市民偏好等級 3 的住宅、對地價與污染的敏感度是無教育者的 3~5 倍 ——
  他們會把好地段的高級住宅填滿，也會第一批從污染區搬走。
- 辦公區需要大學學歷才不扣分（大學畢業在工廠工作反而扣 10）。想發展辦公區就得先有大學。

**沒有學校的城市**會穩定運作，但停在一個特定的形狀：人口全是無教育、生育率最高
（5%）、住宅停在等級 1、辦公區招不到合適的人、對污染與地價都不敏感。這不是壞掉，
是一座工業城市 —— 只是它永遠不會變成別的樣子。

**代價**：學校要蓋要維護，而就學中的市民不影響工作（成人可以邊工作邊讀，只是慢
3 倍）。學校的實質成本是預算，不是勞動力。

## 移民系統

### 城市吸引力

```
分數 = 0
  + (有工作機會 ? +20 : 0)
  + (有空房 ? +20 : 0)
  + 平均幸福度 × 0.5
  - 稅率 × 0.5
  - 污染 × 0.2
  - 犯罪率 × 0.3
  - 失業率 × 60
```

範圍: 0~100

### 移入 (Immigration)

- 吸引力 > 40 時才會有移民
- 移入上限 = min(人口 1%, 空房數, 需求上限)
- 需求上限 = ceil((吸引力-40)/10) × max(1, floor(log10(人口)))
- 有 0.7~1.5 倍隨機抖動

### 家庭移入

移入以家庭為單位：

| 類型 | 權重 | 成人 | 小孩 |
|------|------|------|------|
| 夫妻帶孩子 | 40% | 2 | 1~2 |
| 年輕夫妻 | 30% | 2 | 0 |
| 單身 | 30% | 1 | 0 |

成人年齡: 55~140 life-weeks（工作年齡）

### 移入者教育分布

基礎權重: NONE=30, ELEMENTARY=25, HIGH_SCHOOL=25, UNIVERSITY=20

修正因素：
- 城市有大學 → 大學+15, 高中+5
- 辦公比例 > 30% → 大學+10, 高中+5
- 工業比例 > 50% → 無教育+10, 小學+5, 大學-10
- 地價 > 150 → 大學+10, 無教育-10
- 低稅 < 7% → 高中+5, 大學+5
- 高稅 > 12% → 無教育+5, 高中-5, 大學-10

### 移出 (Emigration)

- 每位市民有自己的忍耐底線，幸福度掉到底線以下就想離開
- 底線 = 教育基礎值 + ±5 隨機（所以同教育程度的鄰居不會同時走光）

| 教育 | 基礎容忍度 |
|------|-----------|
| NONE | 18 |
| ELEMENTARY | 22 |
| HIGH_SCHOOL | 26 |
| UNIVERSITY | 30 |

- 移出上限 = 0~10 隨機 + 人口 × (1%~3%)

### 自然流失

- 基礎率: 人口 × 0.2%，上限 5 人/tick
- 吸引力 ≥ 70 → 流失率 0（好城市無自然流失）
- 吸引力 40~70 → 線性遞減

## 出生系統

### 合格條件

- 生命階段 = ADULT
- 年齡 ≤ 130 life-weeks
- 有住所 (`homeId != null`)
- 同住所的嬰兒+兒童數 < 上限

### 幼兒上限

```
max(2, floor(住宅容量 / 4))
```

### 生育率

按教育等級調整：

| 教育 | 基礎率 | 幸福門檻 | 幸福加成 |
|------|--------|---------|---------|
| NONE | 5% | > 60 | +4% |
| ELEMENTARY | 4% | > 65 | +3% |
| HIGH_SCHOOL | 3.5% | > 70 | +2.5% |
| UNIVERSITY | 3% | > 75 | +2% |

教育程度越高，基礎生育率越低，但幸福門檻也越高。

## 住房偏好評分 (Housing Score)

市民在選擇住所時會根據個人條件對候選住宅進行評分。

### 評分因素

#### 1. 建築等級匹配 (Level Match)

市民依教育程度偏好不同等級的住宅：

| 教育 | 偏好等級 | 完全匹配 | 差1級 | 差2級 |
|------|---------|---------|-------|-------|
| NONE | 1 | +30 | +10 | -10 |
| ELEMENTARY | 1 | +30 | +10 | -10 |
| HIGH_SCHOOL | 2 | +30 | +10 | -10 |
| UNIVERSITY | 3 | +30 | +10 | -10 |

#### 2. 地價偏好 (Land Value)

高教育市民更在意地價：

| 教育 | 權重 |
|------|------|
| NONE | 0.02 |
| ELEMENTARY | 0.03 |
| HIGH_SCHOOL | 0.05 |
| UNIVERSITY | 0.10 |

分數 = (地價 - 128) × 權重。地價 128 為中性點。

#### 3. 污染敏感度

高教育市民對污染更敏感：

| 教育 | 權重 |
|------|------|
| NONE | 0.03 |
| ELEMENTARY | 0.04 |
| HIGH_SCHOOL | 0.05 |
| UNIVERSITY | 0.10 |

分數 = -(地面污染 × 0.7 + 噪音污染 × 0.3) × 權重

#### 4. 通勤距離

基於住所到工作場所的曼哈頓距離：

| 距離 | 分數 |
|------|------|
| ≤ 5 | +15 |
| > 20 | -15 |
| 5~20 | 線性插值 (15 → -15) |

#### 5. 服務與公園

- 服務覆蓋: 0~6 對應 0~10 分
- 公園覆蓋: +5 分

## 住房分配 (Housing Assignment)

無家可歸的市民會從有空位的住宅裡挑分數最高的幾棟，然後隨機選一棟住進去 ——
不是每次都選第一名。這是刻意的：全部挑最高分的話，新蓋好的那一棟會被瞬間塞滿，
旁邊同樣好的房子卻沒人住。

找工作是同一套做法，換成就業評分，而且只考慮道路走得到的工作場所。

## 住房搬遷 (Relocation)

不滿意住所的市民可能搬家。

### 搬遷條件

| 條件 | 值 |
|------|-----|
| 幸福度低於這個值才考慮搬 | 35 |
| 新住所分數要高出這麼多才值得搬 | 20 |
| 每輪最多搬走不滿市民的比例 | 5% |
| 多久檢查一次 | 每 60 ticks |

不滿意的市民不會全部一起搬 —— 每輪只動 5%，所以改善一個街區的效果是逐步顯現的，
反過來讓一個街區變差也不會馬上看到人去樓空。

---

## 換工作 (Job Relocation)

通勤路徑失敗或過長的市民會嘗試換工作。

### 觸發條件

| 原因 | 優先級 | 說明 |
|------|--------|------|
| 走不到 | 緊急 | 從家到公司沒有可通行的路線 |
| 通勤太久 | 一般 | 通勤時間超過 60 |
| 不開心 | 一般 | 幸福度低於 35 |

### 換工作的條件

- 新工作的評分必須比現職高 15 分以上才會換 —— 差不多的工作不值得換
- 一般案件每輪最多動 5% 的人；「走不到」不受這個限制
- 走不到又找不到任何可達的工作 → 變成失業

**這代表什麼**：拆掉一段路把某個工業區與住宅區切開，那一區的市民不會靜靜地卡住，
而是會在幾輪之內全部換工作或失業。反過來，補上一條連通道路也會讓失業者陸續找回
工作 —— 但不是立刻，換工作是分批進行的。

## 通勤時間

市民對城市最直接的感受。它同時決定了兩件事：**要不要換工作**，以及**搬家時
哪一間房子比較好**。

### 怎麼算

市民出門時會比較兩種走法，選比較快的：

| 走法 | 時間 |
|------|------|
| 開車 | 直線距離 × (1 + 壅塞程度) |
| 走路 | 沿人行道的距離 ÷ 步行速度 |
| 大眾運輸 | 走到站 + 等車 + 乘車 + 走到目的地 |

**走路比開車慢得多。** 開車是「一格一 tick」，走路是 9 km/h 對 30 km/h，也就是
0.3 格/tick —— 穿越同一格要花三倍多的時間。（這個 30 不是車速設定，是把「走路
9 km/h」換算成遊戲單位的分母。）

等車時間 = 班距 × 0.5 × 擁擠倍率。班距 = 路線整圈時間 ÷ 車輛數，所以**加車會讓
等車變短**；載重超過八成之後擁擠倍率開始爬升，最多等四倍。

距離很近（3 格以內）就直接走路。大眾運輸只要不比開車慢過 1.5 倍就會被選 ——
市民願意為了不開車忍受一點慢。

### 走路還要再打一次折扣

同樣一分鐘，走的比坐的難熬。比較時走路那一段會被乘上一個權重，而**權重依教育程度
而異**：

| 教育程度 | 權重 | 不塞車時願意走多遠去搭捷運 |
|---|---:|---:|
| 無 | 2.0 | 2 格 |
| 國小 | 1.6 | 3 格 |
| 高中 | 1.2 | 5 格 |
| 大學 | 0.8 | 走滿上限（8 格） |

大學那一格低於 1，意思是**寧可走路**，即使慢一點 —— 受過高等教育的人更在意健康與
環境。所以蓋大學不只是提高稅收：它會把市民從「非開車不可」推向「走得到就走」，
反過來紓解壅塞。

這個權重只影響市民**怎麼選**。你在通勤時間圖層與總覽面板看到的數字，一律是他實際
花掉的時間。

### 「走到站」是走出來的，不是量出來的

「這個市民走不走得到那個站牌」是沿著人行道算的，不是在地圖上量直線。差別在馬路：
**市民只在路口過馬路**，所以對街的站牌雖然看起來只有兩格，實際上得走到最近的路口
再繞回來。路口間距 8 格的話那兩格要走 7.44 格 —— 超過公車 4 格的步行上限，這個
市民其實搭不到那班公車，他會開車。

**步行上限依運具而異**：

| 運具 | 上限 | 理由 |
|---|---:|---|
| 公車 | 4 格 | 站密、班次疏、車慢 —— 不必也不值得走遠 |
| 渡輪 | 6 格 | 碼頭稀疏但船慢 |
| 捷運 / 火車 | 8 格 | 快、班次密、站稀疏 |

實務上這代表：

- **站牌蓋在路段中間，只服務得到同一側**
- **蓋在路口旁邊，兩側都涵蓋得到**
- 一條完全沒有岔路的長直路，兩側永遠互不相通

隔著河、隔著整排建築的格子同樣不算 —— 直線距離看不見那些，人行道看得見。

### 這條線畫在哪

通勤時間超過 **60** 就會想換工作；搬家時，**15 以內**的房子拿滿分、**超過 60**
吃滿扣分。

各種城市實測的中位數：

| 城市 | 通勤時間中位數 |
|------|--------------|
| 住商混合的小鎮 | 11 |
| 緊湊的城市 | 25 |
| 分區但路況普通 | 43 |
| 分區、沒有大眾運輸 | 70 |
| 分區、路全塞死 | 108 |
| **家與公司都在站旁邊的人** | **16 ~ 34** |

最後一列是重點：**住在站旁邊的市民不管住多遠，通勤時間都在線內。**

### 為什麼是時間而不是距離

因為距離沒辦法改善，時間可以。

一個人住城北、公司在城南，你沒辦法讓他們變近 —— 但你可以蓋一條捷運。實測同一個
家、同一份工作，家與公司都在站旁邊的人，通勤時間從 62 降到 24。

如果用距離判斷，這個人蓋不蓋捷運都一樣「住得太遠」，會一直想換工作，而玩家的
建設完全得不到回報。改看時間之後：

- **蓋一條捷運** → 沿線居民的通勤時間集體下降 → 想換工作的人變少，站旁的房子變搶手
- **讓路塞爆** → 全城通勤時間上升 → 開始有人想換工作、想搬家
- **城市攤太大又沒有運輸** → 四成的人處在想換工作的狀態

而站的覆蓋範圍是有限的（走得到才算，約 5 格）。一條線只服務一條走廊 ——
城市邊緣的人通勤時間不會有任何變化，那正是「那裡缺一條線」的訊號。

### 在哪裡看得到

**地圖上**：Layers → ⏱ Commute。住宅建築依住戶的平均通勤時間上色，綠到紅，
滿格就是上面那條 60 的線；大眾運輸站牌標成青色，用來看「這片紅色離最近的站
有多遠」。詳見[覆蓋層](overlay-system.md#通勤時間覆蓋層)。

**數字**：Overview → Traffic。中位數、平均、超過門檻的比例、分布長條、交通
方式分布，以及通勤最久的 5 個住宅區（點一下把鏡頭移過去）。

交通方式分布是判斷「我蓋的捷運有沒有人在用」最直接的指標 —— 蓋了線卻沒人搭，
通常是站離住宅或工作地太遠，走不到。

## 查看單一市民

點擊市民會開啟他的詳細面板，看得到生命階段、教育程度、幸福度、健康值，以及他的
住所與工作地點。面板可以同時開好幾個，與建築面板並排。

想知道某一區為什麼在流失人口，最快的方法是點開幾個住在那裡的市民 —— 幸福度的
扣分項會直接告訴你是污染、通勤、稅率還是缺服務。
