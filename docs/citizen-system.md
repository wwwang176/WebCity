# 市民系統 (Citizen System)

市民是城市的核心，每位市民都是獨立的個體，擁有年齡、教育、幸福度等屬性。

---

## 市民屬性

| 屬性 | 型別 | 說明 |
|------|------|------|
| `id` | number | 唯一識別碼（自動遞增，載入存檔時自動調整避免重複） |
| `birthTick` | number | 出生時的模擬 tick |
| `age` | number | 年齡（生命週，life-weeks） |
| `lifeStage` | LifeStage | 生命階段 |
| `education` | EducationLevel | 教育程度 |
| `happiness` | number | 幸福度 (0-100) |
| `health` | number | 健康值 |
| `homeId` | string \| null | 住所位置 `"x,y"` |
| `workplaceId` | string \| null | 工作場所位置 `"x,y"` |
| `unemployedSince` | number \| null | 失業起始 tick |
| `homelessSince` | number \| null | 無家可歸起始 tick |
| `emigrationTolerance` | number | 個人移出閾值（幸福度低於此值會想離開） |
| `educationProgress` | number | 教育進度（0=未就學，>0=就學中） |

## 生命階段 (Life Stage)

使用「生命週」(life-weeks) 作為年齡單位。完整一生約 260 週（遊戲時間約 5 年）。

### 年齡增長

```
每 tick 增加年齡 = AGE_PER_TICK = 0.006 life-weeks
```

在 3 倍速下，一個市民從出生到自然死亡約需 1 小時現實時間。

### 階段劃分

| 階段 | 年齡範圍 (life-weeks) | 說明 |
|------|----------------------|------|
| BABY | 0 ~ 8 | 嬰兒，不可工作或就學 |
| CHILD | 9 ~ 32 | 兒童，可就讀小學 |
| TEEN | 33 ~ 52 | 青少年，可就讀高中 |
| ADULT | 53 ~ 200 | 成人，可工作、可就讀大學 |
| SENIOR | 201+ | 老年，退休 |

### 工作年齡

只有 ADULT 階段（53~200 life-weeks）的市民可以工作。TEEN 和 SENIOR 不被視為工作人口。

## 死亡系統

每天進行一次死亡判定（浴缸曲線 + 醫院負載 + 污染）。

### 死亡率公式

```
finalRate = baseRate × elderlyMult × hospitalMult × pollutionMult
```

### 基礎死亡率 (baseRate)

| 階段 | 每日死亡率 | 無醫療存活率 |
|------|-----------|-------------|
| BABY | 0.0016 | ~91% |
| CHILD | 0.00015 | ~98% |
| TEEN | 0.00015 | ~98% |
| ADULT | 0.0005 | ~60% |
| SENIOR | 0.006 | ~8% |

### 修正因子

- **高齡加成 (elderlyMult)**: age > 240 時，每多 1 life-week 死亡率倍率 +0.25
- **醫院負載 (hospitalMult)**: 依醫院負載率連續變化（詳見[醫療服務](services-system.md#醫院負載系統)）
  - 有覆蓋且負載 ≤ 100%: × 0.3（降低 70%）
  - 有覆蓋且負載 100%~200%: × 0.3~1.0（線性惡化）
  - 有覆蓋且負載 ≥ 200%: × 1.0（等同無覆蓋）
  - 無覆蓋: × 1.0
- **污染懲罰 (pollutionMult)**: 無醫院覆蓋時，住所污染增加死亡率
  - 有覆蓋: × 1.0（污染效果已透過醫院超載反映）
  - 無覆蓋: × (1 + 0.5 × pollution/255)，最高 × 1.5
- **硬性上限**: age > 280 → 立即死亡

### 範例（SENIOR，base=0.006）

| 情境 | 計算 | 日死亡率 |
|------|------|---------|
| 有醫院、無污染 | 0.006 × 0.3 × 1.0 | 0.0018 |
| 有醫院、高污染但未超載 | 0.006 × 0.3 × 1.0 | 0.0018 |
| 有醫院、超載 150% | 0.006 × 0.65 × 1.0 | 0.0039 |
| 無醫院、無污染 | 0.006 × 1.0 × 1.0 | 0.006 |
| 無醫院、高污染 | 0.006 × 1.0 × 1.5 | 0.009 |

## 健康值 (Health)

每位市民的健康值 (0~100) 影響死亡率和生活品質。

### 基礎值: 50

### 加成因素

| 因素 | 效果 | 說明 |
|------|------|------|
| 醫院覆蓋 | +0~30 | `(1 - costRatio) × 30`，越近加成越高 |
| 公園覆蓋 | +5 | 住所在公園覆蓋範圍內 |
| 有住所 | +10 | 有家的市民比無家可歸者更健康 |

### 減損因素

| 因素 | 效果 | 說明 |
|------|------|------|
| 污染 | -0~15 | `(pollution / 100) × 15` |
| 老年衰退 | -0~10 | age > 200 時線性增加 |

### 計算公式

```
health = 50
  + 醫院覆蓋加成 (0~30，基於道路距離)
  + 公園覆蓋加成 (+5)
  - 污染懲罰 (0~15)
  + 有住所加成 (+10)
  - 老年衰退 (0~10，age 201~260 線性)
clamp(0, 100)
```

## 教育系統

### 教育等級

```
NONE        無教育
ELEMENTARY  小學
HIGH_SCHOOL 高中
UNIVERSITY  大學
```

### 升學路徑

```
NONE → ELEMENTARY（需要小學覆蓋）
ELEMENTARY → HIGH_SCHOOL（需要高中覆蓋）
HIGH_SCHOOL → UNIVERSITY（需要大學覆蓋）
```

### 畢業時間

使用 ×100 精度整數計算，避免浮點誤差：

| 學校 | 畢業門檻 | 兒童/青少年耗時 | 成人耗時 | 老年耗時 |
|------|---------|---------------|---------|---------|
| 小學 | 15,000 | 150 ticks | ~455 ticks | 750 ticks |
| 高中 | 12,000 | 120 ticks | ~364 ticks | 600 ticks |
| 大學 | 10,000 | 100 ticks | ~303 ticks | 500 ticks |

### 學習速度

| 年齡段 | 每 tick 進度 |
|--------|-------------|
| 兒童/青少年 (≤52 wk) | 100 |
| 成人 (53~200 wk) | 33（約 3 倍慢） |
| 老年 (201+ wk) | 20（5 倍慢） |

每 tick 有 80%~120% 的隨機抖動，使畢業時間自然分散。

### 教育 Tick 流程

**Phase 1 — 推進已在學的學生**:
1. 已在學的學生（`educationProgress > 0`）
2. 若失去住所或學校覆蓋 → 暫停（不重置進度）
3. 進度 += jitteredSpeed(學習速度)
4. 進度達到門檻 → 畢業，教育等級提升

**Phase 2 — 招收新生**:
1. 有住所、未在學、年齡 ≥ 9 的市民
2. 住所在學校覆蓋範圍內
3. 學校有剩餘容量
4. → 開始就學

## 移民系統

### 城市吸引力

```
分數 = 0
  + (有工作機會 ? +20 : 0)
  + (有空房 ? +20 : 0)
  + 平均幸福度 × 0.5
  - 稅率 × 0.5
  - 污染 × 0.2
  - 犯罪率 × 0.3
  - 失業率 × 60
```

範圍: 0~100

### 移入 (Immigration)

- 吸引力 > 40 時才會有移民
- 移入上限 = min(人口 1%, 空房數, 需求上限)
- 需求上限 = ceil((吸引力-40)/10) × max(1, floor(log10(人口)))
- 有 0.7~1.5 倍隨機抖動

### 家庭移入

移入以家庭為單位：

| 類型 | 權重 | 成人 | 小孩 |
|------|------|------|------|
| 夫妻帶孩子 | 40% | 2 | 1~2 |
| 年輕夫妻 | 30% | 2 | 0 |
| 單身 | 30% | 1 | 0 |

成人年齡: 55~140 life-weeks（工作年齡）

### 移入者教育分布

基礎權重: NONE=30, ELEMENTARY=25, HIGH_SCHOOL=25, UNIVERSITY=20

修正因素：
- 城市有大學 → 大學+15, 高中+5
- 辦公比例 > 30% → 大學+10, 高中+5
- 工業比例 > 50% → 無教育+10, 小學+5, 大學-10
- 地價 > 150 → 大學+10, 無教育-10
- 低稅 < 7% → 高中+5, 大學+5
- 高稅 > 12% → 無教育+5, 高中-5, 大學-10

### 移出 (Emigration)

- 市民幸福度 < 個人 `emigrationTolerance` 時想離開
- 個人容忍度 = 教育基礎值 + ±5 隨機

| 教育 | 基礎容忍度 |
|------|-----------|
| NONE | 18 |
| ELEMENTARY | 22 |
| HIGH_SCHOOL | 26 |
| UNIVERSITY | 30 |

- 移出上限 = 0~10 隨機 + 人口 × (1%~3%)

### 自然流失

- 基礎率: 人口 × 0.2%，上限 5 人/tick
- 吸引力 ≥ 70 → 流失率 0（好城市無自然流失）
- 吸引力 40~70 → 線性遞減

## 出生系統

### 合格條件

- 生命階段 = ADULT
- 年齡 ≤ 130 life-weeks
- 有住所 (`homeId != null`)
- 同住所的嬰兒+兒童數 < 上限

### 幼兒上限

```
max(2, floor(住宅容量 / 4))
```

### 生育率

按教育等級調整：

| 教育 | 基礎率 | 幸福門檻 | 幸福加成 |
|------|--------|---------|---------|
| NONE | 5% | > 60 | +4% |
| ELEMENTARY | 4% | > 65 | +3% |
| HIGH_SCHOOL | 3.5% | > 70 | +2.5% |
| UNIVERSITY | 3% | > 75 | +2% |

教育程度越高，基礎生育率越低，但幸福門檻也越高。

## 住房偏好評分 (Housing Score)

市民在選擇住所時會根據個人條件對候選住宅進行評分。

### 評分因素

#### 1. 建築等級匹配 (Level Match)

市民依教育程度偏好不同等級的住宅：

| 教育 | 偏好等級 | 完全匹配 | 差1級 | 差2級 |
|------|---------|---------|-------|-------|
| NONE | 1 | +30 | +10 | -10 |
| ELEMENTARY | 1 | +30 | +10 | -10 |
| HIGH_SCHOOL | 2 | +30 | +10 | -10 |
| UNIVERSITY | 3 | +30 | +10 | -10 |

#### 2. 地價偏好 (Land Value)

高教育市民更在意地價：

| 教育 | 權重 |
|------|------|
| NONE | 0.02 |
| ELEMENTARY | 0.03 |
| HIGH_SCHOOL | 0.05 |
| UNIVERSITY | 0.10 |

分數 = (地價 - 128) × 權重。地價 128 為中性點。

#### 3. 污染敏感度

高教育市民對污染更敏感：

| 教育 | 權重 |
|------|------|
| NONE | 0.03 |
| ELEMENTARY | 0.04 |
| HIGH_SCHOOL | 0.05 |
| UNIVERSITY | 0.10 |

分數 = -(地面污染 × 0.7 + 噪音污染 × 0.3) × 權重

#### 4. 通勤距離

基於住所到工作場所的曼哈頓距離：

| 距離 | 分數 |
|------|------|
| ≤ 5 | +15 |
| > 20 | -15 |
| 5~20 | 線性插值 (15 → -15) |

#### 5. 服務與公園

- 服務覆蓋: 0~6 對應 0~10 分
- 公園覆蓋: +5 分

## 就業偏好評分 (Workplace Score)

### 教育-區域匹配

不同教育程度適合不同類型的工作場所：

| 教育 | 辦公 | 工業 | 商業 |
|------|------|------|------|
| NONE | -10 | +10 | 0 |
| ELEMENTARY | -5 | +5 | +5 |
| HIGH_SCHOOL | +5 | 0 | +5 |
| UNIVERSITY | +15 | -10 | 0 |

### 道路距離評分

基於 Dijkstra 道路實際距離：

| 距離 | 分數 |
|------|------|
| 不可達 | -20 |
| ≤ 10 | +15 |
| > 40 | -15 |
| 10~40 | 線性插值 |

## 住房分配 (Housing Assignment)

### 偏好分配演算法

1. 遍歷所有無住所的市民
2. 收集有空位的候選住宅（最多取樣 30 個）
3. 對每個候選住宅計算住房偏好分數
4. 從前 3 名中隨機選擇（避免所有市民擠同一棟）
5. 分配住所

### 就業分配演算法

與住房分配類似，但：
- 候選為有空位的工作場所
- 使用就業偏好分數
- 可選的道路可達性過濾（只分配道路可達的工作場所）

## 住房搬遷 (Relocation)

不滿意住所的市民可能搬家。

### 搬遷條件

| 參數 | 預設值 | 說明 |
|------|--------|------|
| `happinessThreshold` | 35 | 幸福度低於此值的市民考慮搬遷 |
| `scoreGap` | 20 | 新住所分數必須比現住所高 20 以上 |
| `maxRelocateRatio` | 5% | 每 tick 最多搬遷不滿市民的 5% |
| `tickInterval` | 60 | 每 60 ticks 執行一次 |

### 搬遷流程

1. 找出幸福度 < 35 的有住所市民
2. 計算當前住所的住房偏好分數
3. 從有空位的候選住宅中找最高分
4. 若最佳候選分數 - 當前分數 ≥ 20 → 搬遷

---

## 換工作 (Job Relocation)

通勤路徑失敗或過長的市民會嘗試換工作。

### 觸發條件

| 原因 | 優先級 | 說明 |
|------|--------|------|
| `failed` | 緊急 | 通勤路徑確認不可達 |
| `long_commute` | 一般 | 通勤路徑長度 > 500 |
| `manhattan_fallback` | 一般 | 無快取路徑，曼哈頓距離 > 15 |
| `unhappy` | 一般 | 幸福度 < 35 |

### 參數

| 參數 | 預設值 | 說明 |
|------|--------|------|
| `commuteLengthThreshold` | 500 | 通勤路徑長度閾值 |
| `manhattanFallback` | 15 | 曼哈頓距離回退閾值 |
| `scoreGap` | 15 | 新工作分數差距門檻 |
| `maxRelocateRatio` | 5% | 非緊急搬遷比例上限 |
| `dijkstraMaxBudget` | 60 | Dijkstra 搜尋預算 |

### 處理流程

1. **緊急 (failed)**: 優先處理，無比例限制
   - 有更好的可達工作 → 換工作
   - 無可達工作 → 變成失業
2. **一般**: 受比例限制
   - 從住所出發 Dijkstra 搜尋可達工作場所
   - 選分數最高且分數差距 ≥ 15 的工作

## 市民詳細面板 (CitizenDetailPanel)

點擊市民可開啟獨立的市民詳細面板，顯示：

- 市民 ID、生命階段、教育程度
- 幸福度、健康值
- 住所位置、工作場所位置

面板作為左側面板堆疊（Left Panel Stack）的一員，與建築面板和轉乘覆蓋面板並存。面板以開啟順序排列（最新開啟的在最右側）。

### 市民 ID 安全機制

`CitizenManager` 使用自動遞增的 `nextId` 計數器。載入存檔恢復市民時，若恢復的市民 ID ≥ 當前 `nextId`，系統會將 `nextId` 調整為 `citizen.id + 1`，防止後續新增市民時產生重複 ID。
